# Trading Analysis Dashboard

## 📌 Project Overview

This project presents an in-depth **Trading Analysis** using **Power BI**. The goal is to transform raw stock trading data into actionable insights that drive informed investment decisions.

From a **Business Intelligence (BI)** perspective, this project demonstrates the application of **data modeling, ETL processes, KPI tracking, and interactive reporting** to support traders and investors in monitoring performance and identifying profitable opportunities.

---

## 🎯 Business Objectives

1. Track overall profit and loss across different time periods.
2. Identify top-performing stocks and underperforming investments.
3. Monitor transaction trends, cumulative profits, and risk exposure.
4. Provide stakeholders with dynamic, interactive dashboards for quick insights.

---

## 🛠️ BI Concepts & Technologies Applied

* **Data Extraction & Transformation (ETL):** Using Power Query to clean and prepare trading data from Excel (Groww reports).
* **Data Modeling:** Establishing relationships between stocks, transactions, and dates.
* **DAX (Data Analysis Expressions):** Creating calculated measures such as Total Profit/Loss, Average Return, and Transaction Count.
* **Dashboarding & Visualization:** Using Power BI visuals to highlight KPIs, trends, and portfolio performance.
* **Drill-Down & Filtering:** Enabling users to explore data by stock, transaction type, or time period.

---

## 📊 Dashboard Features

* **Profit & Loss Overview:** Total gains/losses, transaction counts, and performance summary.
* **Trend Analysis:** Performance over time for individual stocks and overall portfolio.
* **Stock Insights:** Best-performing and underperforming stocks.
* **Transaction Details:** Analysis of buy/sell transactions with detailed metrics.
* **Portfolio Health:** Insights into risk exposure and diversification.

## 🚀 How to Use

1. Download the `Trading_Analysis.pbix` Power BI file.
2. Open it in **Power BI Desktop**.
3. Load the Excel dataset (Groww profit/loss report).
4. Interact with the dashboard by applying filters and drilling down into stocks and transactions.
